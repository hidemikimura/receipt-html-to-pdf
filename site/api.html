読み込み

ESM のみです。ソースをそのまま使うか、minify 済みの単一ファイルを使うかを選べます。

// ソース（バンドラーが tree-shaking できる）
import { registerFont, htmlToPdf } from '@hidemikimura/receipt-html-to-pdf';

// minify 済みの単一ファイル（gzip 19KB）
import { registerFont, htmlToPdf } from '@hidemikimura/receipt-html-to-pdf/min';

CDN から読み込む（ビルド不要）

npm や バンドラーを使わず、HTML に <script type="module"> を 1 つ置くだけで動きます。dist/ の minify 済みファイルは依存ゼロの単一 ESM なので、jsDelivr や unpkg の URL をそのまま読めます。

<script type="module">
  import { registerFont, htmlToPdf, downloadPdf }
    from 'https://cdn.jsdelivr.net/npm/@hidemikimura/receipt-html-to-pdf@0.3.0/dist/receipt-html-to-pdf.min.js';

  await registerFont({ family: 'BIZ UDPGothic', src: '/fonts/BIZUDPGothic-Regular.ttf' });
  downloadPdf(await htmlToPdf(document.querySelector('#receipt')), 'receipt.pdf');
</script>

バージョンは固定するのが安全です。@0.3.0 を外すと最新版が読み込まれ、更新のたびに挙動が変わる可能性があります。

unpkg でも同じです。esm.sh は依存の解決までしてくれますが、このライブラリは依存ゼロなので、上のように dist/ を直接指すのが一番速く読み込めます。

<script type="module">
  import { registerFont, htmlToPdf }
    from 'https://unpkg.com/@hidemikimura/receipt-html-to-pdf@0.3.0/dist/receipt-html-to-pdf.min.js';
</script>

通常の <script> から使う

グローバル変数を配るビルド（IIFE / UMD）は用意していませんが、モジュールスクリプトを 1 行挟めば window に載せられます。以降は type="module" でない普通のスクリプトやインラインの onclick からも呼べます。

<script type="module">
  import * as ReceiptHtmlToPdf
    from 'https://cdn.jsdelivr.net/npm/@hidemikimura/receipt-html-to-pdf@0.3.0/dist/receipt-html-to-pdf.min.js';
  window.ReceiptHtmlToPdf = ReceiptHtmlToPdf;
  await ReceiptHtmlToPdf.registerFont({ family: 'BIZ UDPGothic', src: '/fonts/BIZUDPGothic-Regular.ttf' });
  document.dispatchEvent(new Event('rhtp-ready'));
</script>

<script>
  document.addEventListener('rhtp-ready', () => {
    document.querySelector('#save').onclick = async () => {
      const { htmlToPdf, downloadPdf } = window.ReceiptHtmlToPdf;
      downloadPdf(await htmlToPdf(document.querySelector('#receipt')), 'receipt.pdf');
    };
  });
</script>

モジュールスクリプトは defer と同じ扱いで、通常のスクリプトより後に実行されます。読み込み完了を待たずに window.ReceiptHtmlToPdf を参照すると undefined になるので、上のようにイベントで知らせるか、ボタン側を最初 disabled にしておきます。

動く一式は examples/cdn.html にあります。ファイル 1 つで、ビルドもサーバーも要りません。

registerFont(font)

PDF に埋め込むフォントを登録します。アプリの起動時に一度だけ呼べば、以降の変換で再利用されます（パース結果はモジュール内にキャッシュされます）。同じ family / weight / style を再登録すると上書きします。

await registerFont({
  family: 'BIZ UDPGothic',   // CSS の font-family と一致させる
  weight: 400,               // 省略時 400
  style: 'normal',           // 'normal' | 'italic'、省略時 'normal'
  src: '/fonts/BIZUDPGothic-Regular.ttf',  // URL / ArrayBuffer / Uint8Array
});

HTML の @font-face と同じファイルを渡してください。 ブラウザが文字幅の計測に使うフォントと、PDF に埋め込むグリフが違うと、文字の位置がずれます。

使えるのは TrueType（glyf アウトライン）の静的 TTF だけです。CFF の OTF・WOFF・WOFF2・TTC は例外になります。可変フォントはデフォルトインスタンスだけが埋め込まれ、console.warn が出ます。

htmlToPdf(input, options?)

HTML を PDF に変換します。input には DOM 要素か HTML 文字列を渡せます。

const pdf = await htmlToPdf(document.getElementById('receipt'), { /* options */ });

返り値は既定で Blob。output で Uint8Array や data URL にもできます。

要素を渡す場合、その要素は DOM 上にあり、スタイルとフォントが適用された状態である必要があります。document.fonts.ready を待ってから呼ぶと確実です。親文書の <html> と <body> の属性（class・lang・data-*）も内部にコピーされるので、body.reissue .watermark のような祖先依存のセレクタもそのまま効きます。

フォントが 1 つも登録されていないと htmlToPdf: no fonts registered の例外になります。

ページ設定

page: {
  size: 'A4',              // 'A3' 'A4' 'A5' 'B4' 'B5' 'Letter' 'Legal'
                           // または { width: '80mm', height: '200mm' }
  orientation: 'portrait', // 'landscape' で横向き
  margin: '15mm',          // 文字列で四辺共通
                           // または { top, right, bottom, left }
}

長さは mm cm in pt pc px を受け付けます（単位なしは px）。レシートプリンタ向けに { width: '80mm', height: '297mm' } のような指定もできます。

ページ分割は、テキストの行・<tr>・<thead>・<tfoot>・<img>・break-inside: avoid の要素を跨がない位置まで自動で繰り上がります。強制改ページは break-before: page / break-after: page。表が次ページへ続くときは <thead> が各ページ先頭に、<tfoot> がそのページ最後の行の直下に繰り返されます。

ヘッダーとフッター

本文とは別の HTML として各ページに合成されます。{{pageNumber}} と {{totalPages}} が置換されます。

footer: '<div style="text-align:center;font-size:8pt">{{pageNumber}} / {{totalPages}}</div>'

高さは 1 ページ目相当の内容で 1 回だけ測り、全ページ共通とみなします。ヘッダー／フッターを付けたぶん本文領域は縮むので、ページ数が変わることがあります。フォントは本文と同じレジストリから引かれるので、テンプレート側でも font-family を指定してください。

進捗と長い文書

変換は途中でイベントループへ戻すので、数百ページの文書でも画面が固まりません（所要時間は 1 割ほど増えます）。進捗表示を出すなら onProgress を配線します。

await htmlToPdf(el, {
  onProgress: (p) => {
    if (p.phase === 'page') bar.value = p.page / p.totalPages;
  },
});

デコード済みの画像データは PDF へ埋め込んだ時点で解放されます。同じ画像を次の変換でも使う場合は読み直しになります（速度よりメモリを優先しています）。

警告の種類

onWarning に届くオブジェクトは { code, message, element?, property?, text? } です。変換は止まりません。

code意味よくある原因
unsupported-css指定された CSS を無視したbox-shadow、グラデーション、縦書きなど。property に対象が入る
missing-glyphグリフが無く □ で代替した丸囲み数字・㈱・㍿ など。text に該当文字が入る
missing-fontfont-family に合うフォントが無く、その文字列を飛ばしたregisterFont し忘れ、または fontFallback 未設定
image-failed画像を読めず描かなかったCORS ヘッダー無しのクロスオリジン画像、404
other内容が本文領域より横に広く、右側が切れる固定幅に padding / border が乗って box-sizing: border-box が無い、縮まない表

右端が切れるのは一番気づきにくい失敗です。A4・余白 15mm なら本文領域は 180mm ちょうど。width: 180mm に padding や border を足すと、box-sizing: border-box が無い限りその分はみ出します。

その他の関数

downloadPdf(pdf, filename)

生成した Blob または Uint8Array をブラウザにダウンロードさせます。<a download> を作ってクリックし、object URL を後始末するだけの補助関数です。

listFonts()

登録済みフォントの一覧（family / weight / style / glyphs）を返します。デバッグ用です。

version

ライブラリのバージョン文字列。package.json と一致することをビルド時に検査しています。

よくある使い方

サーバーに保存する

const pdf = await htmlToPdf(el, { output: 'blob' });
const form = new FormData();
form.append('file', pdf, 'receipt.pdf');
await fetch('/api/receipts', { method: 'POST', body: form });

画面には出さずに PDF だけ作る

要素は DOM 上にある必要がありますが、画面外に置けば見えません。display: none はレイアウトされないため使えません。

<div id="receipt" style="position:fixed;left:-10000px;top:0">…</div>

Shadow DOM の中身を変換する

親文書のスタイルシートは Shadow DOM に継承されません。CSS を明示的に渡してください。

const css = `@font-face { font-family:"BIZ UDPGothic"; src:url("/fonts/BIZUDPGothic-Regular.ttf") }
             .receipt { font-family:"BIZ UDPGothic"; }`;
const pdf = await htmlToPdf(this.renderRoot.querySelector('.receipt'), {
  stylesheets: [css],
});

印刷用スタイルをそのまま使う

既に @media print で帳票のスタイルを作ってあるなら、そのまま適用できます。

const pdf = await htmlToPdf(el, { mediaPrint: true });

フォントを事前に取得して使い回す

URL ではなくバイト列も渡せます。複数の画面で使うなら一度取得して保持しておくと無駄がありません。

const bytes = new Uint8Array(await (await fetch('/fonts/x.ttf')).arrayBuffer());
await registerFont({ family: 'X', src: bytes });
