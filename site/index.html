ブラウザだけで、選択できる PDF に。

HTML/CSS で組んだ帳票を、サーバーを介さずテキスト選択・検索できるベクター PDF に変換します。日本の領収証・適格請求書のために作りました。

依存ゼロ gzip 19KB 日本語フォント埋め込み 複数ページ対応 MIT
ブラウザで試す 使い方を見る

何が違うのか

HTML を PDF にする方法はいくつもありますが、「ブラウザだけで動く」「HTML/CSS で書ける」「テキストが選択できる」の三つを同時に満たすものがありませんでした。

方法仕組み困ること
html2canvas + jsPDF画面を画像にして PDF に貼るテキストを選択・検索できない。拡大すると粗い。ファイルが重い
pdfmake / pdf-lib独自 DSL で座標を指定HTML/CSS で書けない。デザイン変更のたびに座標を計算し直す
Puppeteer などサーバー側の headless ブラウザPDF 生成のためだけにサーバーが要る
このライブラリブラウザの計算結果を読み取り、PDF のベクター命令に変換レイアウトはブラウザ任せ。描画系の一部 CSS が未対応

仕組み

レイアウトエンジンは実装していません。非表示の <iframe> に用紙幅で HTML を描画させ、ブラウザが計算した座標・色・フォント情報を getBoundingClientRect() と Range.getClientRects() で読み取り、それを PDF の描画命令に変換します。

つまり Flexbox も Grid もテーブルも、日本語の行分割と禁則も、ブラウザが表示したとおりに出ます。ライブラリが責任を持つのは「見えているものを、同じ位置に PDF へ書き出すこと」だけです。

テキストはテキストのまま

グリフをベクターで描き、ToUnicode を付けて埋め込むので、選択・コピー・検索・拡大がすべて効きます。

フォントはサブセット化

使った文字のグリフだけを取り出して埋め込みます。日本語フォントでも PDF は数十 KB 台に収まります。

複数ページも自動で

行や表の行を跨がない位置で分割し、<thead> と <tfoot> は各ページに繰り返します。

使い方

npm install @hidemikimura/receipt-html-to-pdf

フォントの登録はアプリの起動時に一度だけ。HTML 側の @font-face と同じファイルを渡すのが大事なところです。ブラウザが計測に使うフォントと、PDF に埋め込むグリフを一致させます。

import { registerFont, htmlToPdf, downloadPdf } from '@hidemikimura/receipt-html-to-pdf';

await registerFont({ family: 'BIZ UDPGothic', weight: 400, src: '/fonts/BIZUDPGothic-Regular.ttf' });
await registerFont({ family: 'BIZ UDPGothic', weight: 700, src: '/fonts/BIZUDPGothic-Bold.ttf' });

const pdf = await htmlToPdf(document.getElementById('receipt'), {
  page: { size: 'A4', margin: '15mm' },
  metadata: { title: '領収証 No. R-2026-000123' },
  onWarning: (w) => console.warn(w.code, w.message),
});

downloadPdf(pdf, 'receipt.pdf');

対応する HTML 側の指定はこうです。

@font-face {
  font-family: "BIZ UDPGothic";
  font-weight: 400;
  src: url("/fonts/BIZUDPGothic-Regular.ttf");
}

npm を使わない場合

dist/ の minify 済みファイルは依存ゼロの単一 ESM なので、CDN の URL をそのまま読めます。ビルドもバンドラーも要りません。

<script type="module">
  import { registerFont, htmlToPdf, downloadPdf }
    from 'https://cdn.jsdelivr.net/npm/@hidemikimura/receipt-html-to-pdf@0.4.0/dist/receipt-html-to-pdf.min.js';
</script>

バージョンは固定してください。通常の <script> から呼びたい場合を含め、詳しくは API リファレンスの「CDN から読み込む」を見てください。

フォントの制約

ブラウザは OS のフォントファイルを読めないため、PDF に埋め込むフォントはアプリ側が渡します。使えるのは TrueType（glyf アウトライン）の静的 TTF だけです。

形式可否
静的 TTF（glyf）✅BIZ UDPGothic、IPAex ゴシックなど
OpenType/CFF（.otf の多く）✕明確なエラーになります
可変フォント△デフォルトインスタンスのみ。Bold が出ません
WOFF / WOFF2 / TTC✕元の .ttf を配信してください

Noto Sans JP を使うときの注意。 Google Fonts 配布版は可変フォント（NotoSansJP[wght].ttf）なので Bold が出ません。GitHub の notofonts 配布版 OTF は CFF で埋め込めません。fonttools varLib.instancer で静的 TTF にしてから渡してください。迷ったら BIZ UDPGothic（SIL OFL、Google Fonts の静的 TTF）が確実です。

できること・できないこと

位置とサイズを決める CSS はブラウザの計算をそのまま使うので、レイアウト系は全部そのとおりに出ます。描画系には対応範囲があります。

出ます

背景色、ボーダー（辺ごと・破線・角丸）、画像（PNG 透過 / JPEG）、opacity、2D transform、overflow: hidden、::before / ::after の文字列

出ません

box-shadow、グラデーション、filter、縦書き、3D transform、インライン <svg>

例外にはなりません

未対応の指定があっても変換は止まらず、onWarning に何が無視されたかが届きます。

AI エージェント向けのスキル

Claude Code などのコーディングエージェントにこのライブラリを使わせるための SKILL.md を同梱しています。フォントの制約、対応 CSS、日本の領収証の記載要件、よくあるエラーの対処が入っています。

mkdir -p .claude/skills
cp -r node_modules/@hidemikimura/receipt-html-to-pdf/skills/receipt-html-to-pdf .claude/skills/
